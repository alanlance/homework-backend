# API 請求速率限制

此領域描述依 API 金鑰限制請求次數的規則與使用量。

## 領域用語

**時間視窗（Window）**：
同一 API 金鑰從首次請求起算的固定長度計數期間。期間內的新請求不延長到期時間；到期後，由下一次請求開啟新的時間視窗。
_避免使用_：滾動視窗、對齊時鐘的視窗

**使用次數（Usage Count）**：
同一 API 金鑰在目前時間視窗內的存取檢查請求總次數，包含允許與因超額而被阻擋的請求。
_避免使用_：成功請求數、已放行次數

**剩餘配額（Remaining Quota）**：
目前時間視窗的請求次數上限扣除使用次數後，仍可使用的次數；最低為 0。
_避免使用_：剩餘使用量

**視窗剩餘時間（Window TTL）**：
目前時間視窗距離到期的剩餘秒數，屬於使用量查詢的資訊。查詢本身不增加使用次數，也不延長時間視窗。
_避免使用_：視窗長度

**首次超額事件（Rate Limit Exceeded Event）**：
同一 API 金鑰在一個時間視窗內，使用次數首次超過請求上限時產生的事件。每個時間視窗最多產生一次，用於非同步稽核與告警。
_避免使用_：每次阻擋事件、拒絕請求日誌
